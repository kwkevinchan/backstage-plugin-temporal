Make links only from `http:` and `https:` URLs: `temporal.webUi.baseUrl` with another scheme gives no "Open in Temporal UI" links, and the Definition tab links the definition file only when its URL is `http:` or `https:`. A `temporal.externalStorage.objectUrl` link is not made when the bucket or key makes a `.` or `..` path segment or the link leaves the template's path, and a memo entry is shown as a stored payload only when it has exactly the form of a reference. The message forms fall back to the JSON field for an input schema larger than 64 KiB, nested more than 32 levels, that cannot be compiled (for example under a Content Security Policy without `'unsafe-eval'`), or whose form fails. The LLM panel puts at most 50,000 characters of a text and 200 messages, parts or tool calls on the page, with a note and a copy button for the rest. The step graph shows the React Flow attribution, at the bottom left.
