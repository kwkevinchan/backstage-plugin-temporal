# @kwkevinchan/backstage-plugin-temporal-common

Shared code of the unofficial Backstage Temporal plugin: API types, annotation
constants (`temporal.io/namespace`, `temporal.io/task-queue`,
`temporal.io/workflow-type`), `isTemporalAvailable`, path helpers and the
permissions: `temporal.workflow.read`, `.history.read`, `.list`,
`.history.list`, and the control permissions `temporal.workflow.start`,
`.signal`, `.update`, `.cancel`, `.terminate` and `.rerun`.
