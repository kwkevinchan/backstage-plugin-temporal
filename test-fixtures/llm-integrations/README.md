# Histories of the official Temporal AI integrations

Event histories of workflows that use the official Temporal AI
integrations, in the protobuf JSON form of
`temporal workflow show --output json`. The backend tests of the built-in
LLM adapters (`plugins/temporal-backend/src/services/llm/adapters.test.ts`)
read them. The models and the MCP server were fakes: no model service was
called. Task queues, workflow types, workflow IDs and worker identities
were renamed, and stack traces cut to their first line.
